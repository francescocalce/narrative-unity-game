# Narrative Unity Game

Videogioco narrativo in prima persona ambientato in una chiesa abbandonata di Gaeta, sviluppato a supporto di una tesi di laurea universitaria.

Progettato e sviluppato interamente in autonomia, dall'architettura del gioco ai puzzle interattivi.

## Caratteristiche

- Esplorazione in prima persona di un ambiente 3D ricostruito
- Architettura modulare a script, per separare logica di gioco, interazioni e narrazione
- Puzzle interattivo integrato nel percorso di gioco
- Effetti di post-processing per l'atmosfera visiva (illuminazione, color grading)

## Tecnologie

- **Motore:** Unity 6
- **Linguaggio:** C#
